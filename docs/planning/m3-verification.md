## 2. 利用者への手引き（U-06・Firefox の 1 回・U-02）

頼む時期: 手順 1 の PR の取り込みの後から、手順 6 の着手の前（手順書の日で 17 日目）まで（decisions #99）。どちらも約 30 分。

1. `main` を引いて `npm ci`、`npm run dev` を起こし、ブラウザで `http://localhost:5173/src/app/dev/youtube.html` を開く。測る間はそのタブを前に出したままにする（隠れると rAF が止まり、YouTube も止まる）。画面の「rAF」が 50 回／秒以上で、「hidden を見た いいえ」のまま測る。
2. **U-06（広告の出る動画）**: 動画 ID の欄に、広告の出る公開動画の URL か ID を入れて「読み込む」。動画 ID は記録に写さない（返す JSON の `videoId` は消してから送ってよい）。
   - プレイヤーの ▶ を押す（「再生（ミュート）」ではなく、自分の ▶）。▶ から本編が始まるまで待つ（プレロール広告が出たら、その state と読みが JSON に残る）。
   - 広告が出ている間に「pauseVideo を今出す」を 1 回押して 3 秒待つ（広告の間に pauseVideo が効くかを見る。押した時刻とその後 500 ms の state が残る）。
   - 本編に入ったら 20 秒ほど流し、Esc → 2 秒 → Space を 1 回。途中に広告が入れば、そのままにして本編に戻るまで待つ。
   - 「JSON を書き出す」を押し、出たファイル（下の欄にも同じ中身）を返す。
   - 広告の出ない環境の見分け: YouTube Premium、広告ブロッカー、一部の動画（埋め込みで広告を出さない設定）では出ない。数回読み直しても広告が出なければ「広告なし」と一言添えて返す。プレロール（▶ の直後）と途中の広告は別に書く。
3. **Firefox で 1 回**: 同じページを Firefox で開き、見本の動画（欄の既定）で「読み込む」→ ▶ → 20 秒 → Esc → Space → 「JSON を書き出す」。見るのは 4 点: 読みの刻み（JSON の `deltas`）、読みの逆行、Esc の後に焦点がページに戻るか、プレイヤーの上でキーを押しても YouTube のショートカット（Space・矢印）が効かないか（disablekb）。気づいた事を一言添えて返す。

4. **U-02（限定公開のクリック動画）**: 主担当が渡す `click.mp4`（黒い静止画にクリック 64 個。100 BPM・頭 3.0 秒・尻 3.0 秒、43.8 秒）を YouTube に上げる。設定は 限定公開・埋め込みを許可・年齢制限なし・「子ども向けではない」（仮。m3-kickoff §7-7・§7-19）。上げたら動画 ID（11 文字）だけを返す（ID はリポジトリに置かない。ID 入りの譜面も作らない）。同じ素は `npm run charts:clicktrack -- --out <置き場>` で作れる（ffmpeg があれば MP4 も）。S5 段 1 で試すときは同じ置き場の `click.mid` を使う。期限は手順 4 の着手（11 日目）、遅くとも手順 11 の着手（27 日目）の前（聞く事 2 の答えは「遅れそう」）。
